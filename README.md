# Task Tracker (FastAPI)

A simple task tracker built with Python and FastAPI to add, view, update and delete tasks.

## Features
- Add a new task
- View all tasks
- Update a task
- Delete a task

## How to run
1. Install packages:
   ```
   pip install -r requirements.txt
   ```
2. Start the server:
   ```
   uvicorn main:app --reload
   ```
3. Open http://127.0.0.1:8000/docs in your browser to try the API.

## Tech Stack
Python, FastAPI, Uvicorn
